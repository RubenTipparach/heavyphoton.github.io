# Heavy Photon — Logo Concepts

Three original logo directions for Heavy Photon Games. Everything is hand-built
vector — a custom blocky display alphabet (no fonts, pure paths) shared across
all three lockups, so the brand stays consistent whichever direction wins.

Open `preview.html` in a browser to see all three side by side.

| # | File | Direction |
|---|------|-----------|
| 01 | `concept1-dropship.svg` | **Dropship Crest** — stealth delta ship in a chamfered shield badge. Patch/sticker energy. Accent: acid volt `#D8FF3E`. |
| 02 | `concept2-mech.svg` | **Visor** — mech pilot helmet with glare-slashed visor; the O in PHOTON lights up to match. Accent: plasma magenta `#FF3E8A`. |
| 03 | `concept3-raygun.svg` | **Heavy Beam** — raygun firing a photon so heavy the beam sags. Accent: ion cyan `#3EE0FF`. |

Shared palette: ink `#0B0E14`, bone `#F2F0E9`.

## Regenerating / tweaking

All three SVGs are generated by `genlogos.py` (no dependencies, stdlib only):

```sh
python3 genlogos.py
```

Colors, letter spacing, and every shape coordinate live at the top of the
script, so remixing a concept is a one-line edit away.
