Privacy Policy: Mining Mike Uploader

Last updated: 31 October 2026

Mining Mike Uploader is a private tool made by Heavy Photon, the developer of the game Mining Mike. It uploads short gameplay videos of Mining Mike to Heavy Photon's own YouTube channel. It has no other users.

YouTube API Services

Mining Mike Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool uses

  • It signs in only to the developer's own Google account and YouTube channel.
  • It uploads videos, titles, descriptions and publish times to that channel, and reads back the status of those uploads.
  • It does not access, collect or store any data about other YouTube users or viewers.

How data is stored and shared

  • The sign-in token is stored only on the developer's own computer, to keep the tool signed in. A local record of uploaded video IDs and publish times is kept beside it.
  • No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time from the Google account's third-party access settings. Deleting the local token file also ends the tool's access.

Contact

Questions about this policy: reach Heavy Photon on Discord.
